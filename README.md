# memcache
memcache is a minimalist, high-performance in-memory cache for Go, featuring built-in sharding, an LRU (Least Recently Used) eviction policy, and TTL-based (Time-to-Live) expiration. It is designed to be embedded directly into your Go applications as a lightweight library.
